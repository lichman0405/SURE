# Security policy

SURE executes/checks developer projects and may process source code, command output and AI session evidence.

For security reports, avoid posting secrets or exploitable private details in a public GitHub issue. Use GitHub private vulnerability reporting if enabled; otherwise contact the repository owner through an appropriate private channel.

Known design boundary: v0.1 does not claim that executing arbitrary project code on the host is safe. See `docs/architecture/EXECUTION_SAFETY.md`.
