# Non-goals and anti-drift guardrails

Challenge any feature that turns SURE into:

- an IDE;
- a coding agent;
- a multi-agent orchestrator;
- a generic CI replacement;
- a PR-only reviewer;
- a generic enterprise governance suite;
- a cloud-hosted LLM gateway;
- a deployment platform.

A feature belongs in v0.1 only if it materially improves:

1. project usability truth;
2. obvious incompleteness/risk detection;
3. AI claim truth;
4. repair/re-check;
5. safe/easy use of those capabilities.
