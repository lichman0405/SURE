# Product evaluation metrics

Traditional unit-test coverage is not enough. SURE needs product-level evals.

Required release metrics on the curated acceptance corpus:

- false green rate on mandatory blocker fixtures: **0**;
- fabricated execution claims: **0**;
- insufficient evidence fixtures that incorrectly become confirmed: **0**;
- mandatory repair-regression fixture caught: **100%**;
- secret redaction mandatory fixtures: **100%**;
- benign-mock false-positive corpus tracked explicitly;
- default user report passes jargon golden tests.

Do not optimize a single numeric score at the expense of honest unknowns.
