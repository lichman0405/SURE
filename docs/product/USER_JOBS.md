# User jobs

## Job 1 — "The AI says it finished my app. Check it."

SURE should inspect current reality and state what can/cannot be verified.

## Job 2 — "I don't understand the code. Tell me what matters."

SURE prioritizes user impact rather than style noise.

## Job 3 — "The AI says all tests pass. Did they?"

SURE checks recorded execution/current project state rather than accepting the sentence.

## Job 4 — "Give the AI exact instructions to fix this."

SURE produces repair requirements + acceptance conditions.

## Job 5 — "Make sure the repair didn't break something else."

SURE re-runs affected/regression checks.

## Job 6 — "Protect me from obviously dangerous agent actions."

SURE offers Standard / Strict / Custom protection without requiring the user to understand low-level policy syntax.
